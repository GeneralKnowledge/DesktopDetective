# Desktop Detective — The Missing Report

A playable prototype: investigate a fictional employee's computer and reconstruct what happened to a missing report.

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## How to play

1. Boot into **TRACE OS** on Daniel Mercer's workstation.
2. Explore Mail, Files, Browser, Messages, Calendar, Notes, Recycle Bin.
3. Use **Search** (Ctrl+K) to cross-reference clues.
4. **Pin** evidence to the Investigation Board.
5. Use the **Notebook** for free-form theories.
6. **Submit Case** when ready — answers are evaluated against hidden case facts (no percentage score).

## Debug

Press **F1** for the developer panel (case truth, evidence importance, reset, reveal all).

## Stack

React · TypeScript · Vite · Tailwind CSS — fully local, no backend.
